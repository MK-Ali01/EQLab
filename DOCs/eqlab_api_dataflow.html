Auth module — includes/auth.php
methodroute / filedescription + output
POSTregister.phpRegisters new user. Validates email uniqueness, hashes password. Returns user_id or error message.
POSTlogin.phpAuthenticates user. Sets $_SESSION['user_id', 'full_name', 'logged_in']. Redirects to dashboard.php.
GETlogout.phpDestroys session. Redirects to index.php.
GETdashboard.phpProtected page. Calls require_login(). Shows user profile + latest EQ scores.
Assessment module — assessment/
methodroute / filedescription + output
GETassessment/questions.phpFetches all questions from DB. Returns: [{question_id, question_text, domain, facet, scale_min, scale_max}]. Nosherwan renders the form.
POSTassessment/submit.phpYOUR FILE. Receives POST['responses'] = [question_id => value]. Creates session, saves raw responses, triggers scoring engine. Returns: {session_id, scores{}}.
POSTassessment/save_progress.phpSaves partial responses mid-assessment. Stores in assessment_sessions with is_complete=0. Returns: {status, saved_count}.
GETassessment/get_progress.phpReturns previously saved partial responses for logged-in user. Allows resume functionality. Returns: {responses{}, last_saved_at}.
Scoring module — scoring/
methodroute / filedescription + output
GETscoring/get_scores.php?session_id=XReturns computed scores for a session. Returns: {domains:{}, facets:{}, overall}. Called by dashboard and results page.
GETscoring/get_history.php?user_id=XReturns all past sessions with scores for trend chart. Returns: [{session_id, date, domain_totals, overall}] ordered by date ASC.
Profiling module — profiling/
methodroute / filedescription + output
GETprofiling/get_profile.php?user_id=XReturns latest EQ profile. Returns: {profile_type, overall_score, strengths[], weaknesses[], priority_facets[], ai_feedback}.
GETprofiling/get_all_profiles.php?user_id=XReturns all historical profiles. Used for analytics dashboard trend comparison. Returns: [{session_id, date, profile_type, overall_score}].
Learning module — recommendations/
methodroute / filedescription + output
GETrecommendations/get_recommendations.phpReturns personalised lessons for user's weak facets. Excludes already-completed lessons. Returns: {priority_facets[], lessons[{lesson_id, title, domain, facet, difficulty}], progress{total, completed, percent}}.
GETrecommendations/get_lesson.php?lesson_id=XReturns full lesson content + associated quizzes. Returns: {lesson{}, quizzes[{quiz_id, question_text, option_a/b/c/d}]}.
POSTrecommendations/log_progress.phpLogs lesson or quiz activity. POST: {lesson_id or quiz_id, action, score_achieved}. Returns: {status, updated_progress{}}.
GETrecommendations/get_progress.php?user_id=XFull learning progress summary. Returns: {lessons_completed, quizzes_passed, completion_percent, domain_progress{}}.
AI feedback module — ai_module/
methodroute / filedescription + output
POSTai_module/ai_feedback.phpCalls external AI API (Claude/OpenAI) with user profile context. Returns AI-generated feedback text. Called internally after profiling — result stored in eq_profiles.ai_feedback.
