## Local Setup
1. Clone repo into `C:/xampp/htdocs/EQLab`
2. Start Apache + MySQL in XAMPP Control Panel
3. Open phpMyAdmin → import `sql/eqlab_schema.sql`
4. Visit `http://localhost/EQLab/`
